# Анимация первого экрана Zayden (sceneai.art): разбор и где применить

Референс: https://sceneai.art/landing-pages?asset=6abb7a7393a97b6a23b6f7d3 — «Zayden Hero Section».
Разбор от 13.10.2026. Код сайта Portfolio не менялся.

## Что разбирал и насколько точно

- На странице SceneAI блок показан не живой вёрсткой, а видео: mp4 1486×1080, 5,6 с, по кругу (https://cdn.sceneai.art/landing-pages/7bf89be4-135f-4464-a4bd-d52adedbd38f.mp4). Исходный код блока продаётся за «Get All Access» — его не открывал, всё ниже восстановлено по видео.
- Видео — запись экрана настоящей страницы (виден курсор мыши). Предполагаю, что скорость записи реальная: курсор движется естественно.
- Смотрел в браузере покадрово: каждые 1/30 с от 0 до 2,8 с и выборочно до конца ролика. Положение букв и строк, ширину плашки кнопки, плотность и резкость персонажа мерил по пикселям кадра.
- Точность таймингов ±0,05 с: запись неровная (~20 разных кадров в секунду, с повторами), а первая буква к первому кадру уже прошла ~40 % пути — запись начата чуть позже старта анимации.
- Размеры ниже — в пикселях кадра высотой 1080 и в процентах от высоты блока.
- В превью только десктоп. Как блок ведёт себя на телефоне, не видно.

## Как это видит посетитель

Вся сцена появления занимает ~2,1 с после открытия страницы, дальше всё стоит.

1. **0–0,9 с — ZAYDEN.** Буквы по одной, слева направо, выезжают снизу вверх из-под невидимой границы по низу строки. Пока буква ниже границы, её не видно.
2. **0,55–1,2 с — мелкие подписи.** «SMART DIGITAL CARD», «GLOBAL ACCESS 24/7», меню «ABOUT / BENEFITS / SECURITY / SUPPORT», «GLOBAL ACCESS» проявляются из размытого пятна в чёткий текст — по словам и строкам, слева направо.
3. **0,95–1,6 с — персонаж.** Из прозрачного и размытого становится плотным и резким, при этом немного поднимается.
4. **1,15–1,75 с — слоган из трёх строк** («ONE CA…», «…DAY», «…EDOM»): каждая строка выезжает снизу из-под границы, строки по очереди.
5. **1,6–2,0 с — кнопка BOOK NOW.** Сначала красная плашка растёт по ширине слева направо, потом на ней из размытия проявляется надпись.
6. **1,8–2,1 с — аватарки по одной, затем строка «RATED 4.9 BY 5+ CLIENTS»** — тоже из размытия.
7. С ~1,85 с — проявление «статуи» под курсором мыши. **Не рассматривается**: основная версия Portfolio мобильная, курсора там нет.

Порядок — сверху вниз и от главного к второстепенному: имя → подписи → персонаж → слоган → кнопка → отзывы.

## Из чего состоит

Четыре приёма. Всё делается обычным CSS (transform, opacity, filter, clip-path), библиотеки не нужны.

### 1. Выезд из-под маски — ZAYDEN и строки слогана

- Строка — контейнер с `overflow: hidden` (или `clip-path: inset(0)`), внутри каждая буква — `inline-block`.
- Старт: буква сдвинута вниз на высоту строки (`translateY(100%)`), конец — `translateY(0)`. Прозрачность не меняется, поворота и масштаба нет — букву просто обрезает нижний край строки.
- Замеры ZAYDEN: высота букв 253 px (23 % высоты блока); граница маски на 25 px ниже низа букв; путь ~278 px (~110 % высоты буквы).
- Одна буква едет 0,6–0,7 с; следующая стартует через ~0,06 с; всё слово из шести букв — ~0,9 с.
- Кривая — резкое торможение: ~2/3 пути за первые 20 % времени, ~86 % — к трети. По замерам это между easeOutQuart и easeOutExpo; близкий готовый вариант — `cubic-bezier(.16, 1, .3, 1)`, он уже есть в проекте (motion.js:15, styles.css:280).
- Строки слогана — тот же приём, но строкой целиком: ~0,45 с на строку, старты ~1,17 / ~1,3 / ~1,4 с (шаг 0,1–0,15 с).

### 2. Проявление из размытия — подписи, меню, надпись кнопки, аватарки, рейтинг

- Старт: `opacity: 0; filter: blur(…)`, конец: `opacity: 1; filter: none`. Сдвига не видно: размытое слово стоит на своём итоговом месте.
- Каждое слово или строка проявляется за ~0,2–0,3 с, следующее — через 0,05–0,1 с.
- Радиус размытия на старте — на глаз 6–10 px. Это оценка: точно по кадрам не измерить.
- Аватарки — тем же приёмом, по одной, шаг ~0,06 с.

### 3. Вход персонажа

- Одновременно: прозрачность 0 → 1, размытие → 0, подъём снизу на ~40 px (~4 % высоты блока).
- Старт ~0,95 с, длительность ~0,6 с, торможение к концу.
- Замеры: плотность фигуры 9 % (0,97 с) → 48 % (1,0) → 70 % (1,1) → 82 % (1,2) → 96 % (1,4) → 100 % (~1,6). Резкость 10 % (1,0) → 44 % (1,2) → 86 % (1,4) → 100 % (1,5). Центр фигуры с 1,0 с поднимается ещё на ~33 px.
- Возможно, есть и лёгкое увеличение на 3–5 %, но замер неуверенный — не утверждаю.

### 4. Плашка кнопки растёт по ширине

- Высота плашки сразу полная, ширина растёт от левого края: 22 % (1,63 с) → 54 % (1,7) → 92 % (1,83) → 100 % (~1,95). Около 0,3–0,35 с.
- Надпись появляется только после плашки — приёмом 2, ~1,85–2,0 с.
- Делается через `clip-path: inset(0 100% 0 0)` → `inset(0)` или фоном-псевдоэлементом со `scaleX(0 → 1)` и `transform-origin: left`.

### Композиция (это не анимация)

Персонаж стоит поверх заголовка и слогана: корона перекрывает буквы ZAYDEN, середина фраз спрятана за фигурой. Для этого нужна вырезанная фигура на прозрачном фоне и вёрстка «текст под картинкой». Эффектность блока во многом держится на этом, а не на движении.

## Куда бы я добавил в Portfolio

### Основное место — первый экран (index.html:25–35)

Почему здесь: это тот же тип блока, что в референсе; посетитель видит его один раз за визит; на телефоне это первое, что открывается. Ниже по странице уже есть свои появления по скроллу — вводить там ещё один стиль не нужно.

Сопоставление. Мобильная раскладка: подпись сверху во всю ширину, «SMM / ПОРТФОЛИО» слева, портрет справа, ниже описание и кнопка (styles.css:143–150, 297–301).

| Что на странице | Приём из референса | Предлагаемые значения |
| --- | --- | --- |
| «Лиза Понетайкина / SMM-специалист» (index.html:27) | 2 — из размытия по словам | по 300 мс, шаг 50 мс, blur 6 px → 0, старт сразу |
| «SMM» (index.html:28) | 1 — буквы из-под маски по очереди | 3 буквы по 650 мс, шаг 60 мс, `cubic-bezier(.16,1,.3,1)`; старт 0,1 с, готово к ~0,9 с |
| «ПОРТФОЛИО» (index.html:28, `em`) | 1 — строка целиком из-под маски | 500 мс, старт 0,3 с |
| Описание (index.html:29) | 2 — абзац целиком из размытия | 400 мс, старт 0,45 с |
| «Написать в Telegram» (index.html:30) | 4 — плашка по ширине, затем надпись приёмом 2 | плашка 350 мс с 0,55 с; надпись 250 мс с 0,8 с; готово к ~1,05 с |
| Портрет (index.html:32–34) | не трогать | уже есть мягкий вход 550 мс (motion.js:8–18) — облегчённый родственник входа персонажа |

Итого ~1,05 с вместо 2,1 с у референса: на телефоне первый экран читают сразу, длинная сцена мешает.

Почему портрет не трогаю:
- В проекте решено, что портрет виден сразу при открытии (AUDIT.md:9, PROJECT.md:10). Вход как у персонажа — с полной прозрачности — это решение отменяет.
- Размытие большого фото на каждом кадре дорого для слабых телефонов. Портрет — самый крупный элемент первого экрана, скорее всего по нему считается скорость загрузки (LCP).

Как это вписать в текущий код (устройство, без кода):
- Без новых зависимостей: CSS-анимации и запуск из motion.js, кривая — из проекта.
- Без JS, при `prefers-reduced-motion` и при печати — всё сразу в итоговом виде, как у текущих появлений (styles.css:278–281, 330–341).
- Скрытое начальное состояние должно включаться до первой отрисовки. motion.js подключён с `defer` (index.html:14) и может выполниться уже после первого кадра — тогда текст мелькнёт и пропадёт. Нужен короткий inline-скрипт в `<head>`, который ставит класс на `<html>`, и страховка: снять класс через ~1,5 с в любом случае.
- Запускать только если страница открыта в самом верху — как сейчас у портрета (`scrollY === 0`, motion.js:11). При открытии по якорю или после обновления в середине страницы ничего не прятать.
- Разбивка «SMM» на буквы не должна ломать экранный диктор: заголовок по-прежнему читается как «SMM ПОРТФОЛИО» (например, буквы с `aria-hidden` плюс скрытый целый текст).
- Плашку кнопки — через `clip-path` с тем же скруглением (`inset(0 100% 0 0 round 12px)`): `scaleX` сплющит углы радиусом 12 px (styles.css:218). Пока плашка не раскрылась, кнопка не нажимается — это ~0,9 с после открытия.

### Дополнительно, по желанию — блок контакта (index.html:109)

Повтор того же мотива в конце страницы: «Давайте обсудим / ваш проект» — строки из-под маски, кнопка — плашкой. Запуск при входе блока в экран через уже существующий наблюдатель (motion.js:29–39) — вместо текущего подъёма на 56 px у `.contact-copy > *` (motion.js:4), а не вдобавок к нему. Это рифма с первым экраном; без неё страница ничего не теряет.

### Куда не стал бы добавлять

- **Заголовки всех разделов** (Кейсы, Сторис, До и после, Услуги, Обо мне, Как мы работаем). Семь одинаковых побуквенных выездов за одну прокрутку превращаются в шум и тормозят чтение; у заголовков уже есть общее появление (styles.css:279–280).
- **Цифры результатов** (1,06 млн, +876, 2,06 млн…). Это данные, которые посетитель читает и сверяет со скриншотом; размытие и маска им мешают.
- **Шапка** (логотип, меню, «Связаться»). Она закреплена и нужна сразу; проявлять меню из размытия — задерживать навигацию.
- **Портрет в полном варианте референса** — см. выше.
- **Проявление под курсором** — исключено: на телефоне нет курсора.
- **Наложение фото на заголовок** — это перестройка первого экрана и новый ассет (вырезанное фото), а не анимация.

## Что не проверено

- Тайминги референса восстановлены по записи экрана с точностью ±0,05 с; радиус размытия и возможное увеличение персонажа — оценки.
- Поведение референса на телефоне неизвестно — в превью только десктоп.
- Локальный сайт Portfolio в браузере не открывал: раскладку первого экрана брал из styles.css. Значения в таблице — предложение; подбираются на телефоне после внедрения.

## Использованные скиллы

- **clone-motion** — только часть про наблюдение: смотреть оригинал в браузере в постоянном размере, снимать контрольные точки по времени, отделять измеренное от оценок. Реализацию и сравнение с локальной версией из этого скилла не делал — нужен был только разбор.
- **find-animation-opportunities** — для выбора места: каждого кандидата проверял по частоте показа, назначению движения, допустимой длительности и тому, не мешает ли движение чтению. Отсюда раздел «Куда бы я добавил» и список отказов.
