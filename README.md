# Портфолио Лизы Понетайкиной

Статический HTML/CSS/JavaScript без сборки. Сохранены винно-кремовая палитра, Arial / Segoe UI / Georgia. Основной сценарий — телефон.

## Запуск

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8000/ . Относительные пути работают и под /Portfolio/.

## Страница

Портрет появляется сразу при загрузке с боковым раскрытием. В кейсах сначала показана работа, затем результаты; статистика открывается в прокручиваемом окне. Просмотры и прирост подписчиков — отдельные фрагменты исходников. Reels не открывают дублирующую галерею.

У кофейни пять сторис разных рубрик, у клиники серии из трёх и двух кадров. Кофейня и первая серия клиники сохраняют наезд целых слайдов при нативном скролле; вторая серия появляется сбоку. Три сравнения до/после показывают телефоны целиком из оригинальных JPG: CSS выделяет каждый телефон, исходные пиксели сохранены. На вертикальном планшете название стоит над кадром. Без JS и при reduced-motion оба кадра сравнения доступны последовательно. Карточки услуг кликабельны целиком.

## Материалы и файлы

- index.html — содержание, ссылки и окна статистики.
- styles.css — оформление и адаптивная композиция.
- script.js — открытие и закрытие статистики, сохранение положения страницы.
- motion.js — появление портрета, блоков и сравнения при скролле.
- assets/prepared — текущая нарезка статистики, Reels и прежние вырезы сравнений; manifest.json хранит исходники и точные координаты. Увеличение 2× с умеренной резкостью, без генеративной замены текста и деталей.
- assets/work — портреты, сторис и прежние подготовленные варианты.
- assets/originals — неизменённые исходные фотографии.
- vendor/photoswipe — сохранённые файлы прежней библиотеки с лицензией; текущая страница их не загружает.
- PROJECT.md / PLAN.md — состояние проекта и история изменений.

После визуальной оценки пользователь одобрил улучшенный вариант Reels: в нём восстановлена чёрная шапка, весь телефон сохранён, внешний фон удалён. Текущий файл — assets/prepared/reels-approved.webp; описание происхождения — reels-approved.json. Увеличенные исходные скриншоты не следует выдавать за восстановление отсутствующих деталей. Контактное фото использует ранее подготовленный contact-restored.png, оптимизированный в WebP.

## Проверка

Для tests/release_checks.cjs, tests/touch_checks.cjs и tests/final_checks.cjs нужен Node.js, Playwright и установленный Edge (или другой установленный Chromium-канал через BROWSER_CHANNEL). Эти зависимости не нужны посетителю сайта. При необходимости:

```sh
npm install --no-save --package-lock=false playwright@1.62.1 sharp
```

При запущенном локальном сервере:

```powershell
$env:PORTFOLIO_URL = 'http://127.0.0.1:8000/'
$env:BROWSER_CHANNEL = 'msedge'
$env:TEST_OUTPUT = 'test-results/release'
node tests/release_checks.cjs
node tests/touch_checks.cjs

# Проверка в WebKit
npx playwright install webkit
$env:BROWSER_ENGINE = 'webkit'
$env:TEST_OUTPUT = 'test-results/release-webkit'
node tests/release_checks.cjs
node tests/final_checks.cjs
# Меню, затухание, отступы: оба движка
node tests/polish_checks.cjs
# Загрузка актуальных четырёх сравнений: холодный кэш и задержанные ответы
node tests/comparison_loading_checks.cjs
```

Проверяются 13 размеров от 360×780 до 2560×1440, включая низкий и горизонтальный экран; размеры сторис и целых телефонов, режим при изменении высоты и повороте, общие поля, статистика, возврат фокуса/прокрутки, однократные появления, reduced-motion и отсутствие JS. touch_checks проверяет нативные жесты через CDP и клавиатуру; final_checks запускает Edge и WebKit, проверяет мышь/касание и клавиатурный фокус, Arial на ширинах 320–430 px и доступность локальных ресурсов. Снимки нужно просматривать отдельно. Эмуляция не заменяет настоящий iPhone. Для проверки /Portfolio/ запустите сервер из родительской папки и задайте PORTFOLIO_URL с этим префиксом.

Повторная нарезка материалов (нужен Sharp):

```sh
node tests/prepare_assets.cjs
```

Остальные сценарии в tests, включая mobile_visual_checks.cjs, сохранены как история предыдущих вариантов интерфейса и не являются приёмкой текущей версии.
