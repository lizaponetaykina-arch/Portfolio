# Портфолио Лизы Понетайкиной

Адаптивный статический сайт: SMM-кейсы, услуги, подход и контакты. HTML, CSS и JavaScript, без установки зависимостей и сборки. Все пути относительные, сайт работает в `/Portfolio/` на GitHub Pages.

## Посмотреть локально

Откройте `index.html` в браузере или запустите любой статический сервер из этой папки. Например, при установленном Python: `python -m http.server 8000`, затем откройте `http://localhost:8000`.

## Опубликовать на GitHub Pages

1. Загрузите содержимое этой папки в корень репозитория `lizaponetaykina-arch/Portfolio` (не папку Portfolio целиком). В корне должен находиться `index.html`, рядом `styles.css`, `script.js`, `.nojekyll` и папка `assets`.
2. В репозитории откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку, в которую загружены файлы (обычно `main`), и папку **/ (root)**. Нажмите **Save**.
5. Дождитесь завершения публикации. Адрес: https://lizaponetaykina-arch.github.io/Portfolio/

Следующие изменения в этой ветке публикуются автоматически. Подробности: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Обновить материалы

- Тексты, статистика и контакты находятся в `index.html`.
- Цвета, шрифты, размеры и мобильная вёрстка — в `styles.css`.
- Просмотр скриншотов — в `script.js`.
- На телефоне портрет расположен рядом с заголовком, описание и кнопки — под ними. Ссылки и кнопки имеют области нажатия не меньше 44 px.
- Блоки появляются по мере прокрутки: движение на 12 px и прозрачность, 460 мс. При `prefers-reduced-motion` появление мгновенное. Без JavaScript весь контент остаётся видимым.
- В просмотре скриншотов кнопка «Увеличить» позволяет читать широкие слайды на телефоне с горизонтальной прокруткой. Escape закрывает окно, фокус возвращается к исходной ссылке.
- Изображения — в `assets/`. PNG сохранены без изменения; кадрирование на странице выполняется CSS. Ссылки открывают полные исходные слайды.

Числа взяты из предоставленной презентации. Периоды просмотров указаны по скриншотам, год в них не виден. Прирост +876 за месяц не привязан к периоду просмотров: даты для него в исходном слайде отсутствуют. Название и имя автора следует подтвердить перед публикацией: имя взято из адреса репозитория. Публичные ссылки Telegram, Instagram и телефон перенесены из презентации.

Формы и сбор персональных данных не используются: кнопки ведут напрямую в Telegram. Внешних шрифтов, аналитики и сторонних скриптов нет.
