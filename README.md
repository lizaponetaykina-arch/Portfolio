# Портфолио Лизы Понетайкиной

Статический сайт на HTML, CSS и JavaScript, без сборки. Исходная винно-кремовая палитра и шрифты Arial / Segoe UI / Georgia сохранены. Основной сценарий — просмотр с телефона.

## Локальный запуск

Из корня репозитория:

```sh
python -m http.server 8000
```

Откройте http://localhost:8000 . Для модулей галереи нужен HTTP-сервер: открытие index.html через file:// не является полноценным способом проверки. Без JavaScript ссылки на изображения продолжают работать.

## Что находится на странице

1. Главный экран с новым портретом IMG_3248.
2. Кейсы автосервиса и паб-ресторана с исходными подтверждёнными результатами.
3. Пять сторис кофейни и пять сторис клиники.
4. Смена визуала: VR-клуб и ресторан переключаются кнопками; автосервис меняется при вертикальной прокрутке. Способы управления разделены.
5. Услуги, обо мне, процесс, контакт.

Галереи поддерживают pinch zoom, double tap, pan, свайп, кнопки, стрелки клавиатуры и Escape. Фокус и положение страницы восстанавливаются после закрытия. При ошибке изображения остаётся ссылка на файл.

## Файлы и материалы

- index.html — контент и группы галерей.
- styles.css — оформление; цветовые и шрифтовые токены в :root.
- script.js — PhotoSwipe, горизонтальные ленты, появления, два независимых вида сравнений.
- assets/work — оптимизированные WebP и честные кадрированные фрагменты исходников.
- assets/work/manifest.json — размеры подготовленных файлов.
- assets/originals — неизменённые 14 файлов из LizaPhoto.
- vendor/photoswipe — локальная закреплённая версия PhotoSwipe 5.4.4 и её MIT-лицензия. CDN во время просмотра не нужен.
- tests — браузерные проверки; эти зависимости не нужны для работы сайта.
- PLAN.md, PROJECT.md, AGENTS.md — состояние и правила продолжения.

При добавлении изображения в галерею укажите href, data-viewer, data-pswp-width, data-pswp-height и data-caption; разместите ссылку внутри data-gallery. У превью должны быть width, height и alt. Оригинал не нужно загружать вместо маленького превью.

Фото главного экрана имеет варианты 480/800/1200 px. Его оригинал сохранён; подготовленные варианты кадрированы без ретуши. Для сравнений вырезаны области сеток аккаунтов, без перерисовки изображений или показателей.

## Движение

Только сравнение автосервиса использует sticky-сцену и нативную прокрутку. Прогресс обратим. При reduced-motion, низком окне или недостатке места сцена становится обычной последовательностью изображений. У VR-клуба и ресторана нет скролл-управления: только кнопки. Без JS видны обе версии всех сравнений.

## Проверка

```sh
python -m pip install -r tests/requirements.txt
python -m playwright install chromium
```

В отдельном терминале запустите сервер. Затем задайте PORTFOLIO_URL и выполните tests/browser_checks.py. По умолчанию адрес проверки — http://127.0.0.1:8765/portfolio/. Для сервера из корня на 8000 используйте http://127.0.0.1:8000/.

PowerShell, пример с уже установленным Edge:

```powershell
$env:PORTFOLIO_URL = 'http://127.0.0.1:8000/'
$env:BROWSER_CHANNEL = 'msedge'
$env:TEST_OUTPUT = 'test-results'
python tests/browser_checks.py
python tests/gesture_checks.py
```

Переменная AXE_PATH может указывать на локальный axe-core 4.10.3 для дополнительного сканирования WCAG. Без неё этот скан пропускается; прочие проверки выполняются. Gesture checks используют CDP Chromium, а не реальное устройство.
