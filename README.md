# Портфолио Лизы Понетайкиной

Статический сайт на HTML, CSS и JavaScript, без сборки. Исходная винно-кремовая палитра и шрифты Arial / Segoe UI / Georgia сохранены. Основной сценарий — просмотр с телефона.

## Локальный запуск

Из корня репозитория:

```sh
python -m http.server 8000
```

Откройте http://localhost:8000 . Для модулей галереи нужен HTTP-сервер: открытие index.html через file:// не является полноценным способом проверки. Без JavaScript ссылки на изображения продолжают работать.

## Что находится на странице

1. Главный экран с новым портретом IMG_3248.
2. Кейсы автосервиса и паб-ресторана с исходными подтверждёнными результатами.
3. Пять примеров сторис кофейни и две серии клиники (3 + 2 кадра). На каждом кадре видны проект, тема и номер.
4. Смена визуала: все три сравнения меняются при вертикальной прокрутке; снимки показаны с полными рамками телефонов.
5. Услуги, обо мне, процесс, контакт.

Галереи поддерживают pinch zoom, double tap, pan, свайп, кнопки, стрелки клавиатуры и Escape. Фокус и положение страницы восстанавливаются после закрытия. Без JavaScript нажатие на изображение открывает исходный файл.

## Файлы и материалы

- index.html — контент и группы галерей.
- styles.css — оформление; цветовые и шрифтовые токены в :root.
- script.js — PhotoSwipe и сохранение фокуса.
- motion.js — появление портрета при загрузке, появления блоков и все три сравнения при скролле.
- assets/work — оптимизированные WebP и честные кадрированные фрагменты исходников.
- assets/work/manifest.json — размеры подготовленных файлов.
- assets/originals — неизменённые 14 файлов из LizaPhoto.
- vendor/photoswipe — локальная закреплённая версия PhotoSwipe 5.4.4 и её MIT-лицензия. CDN во время просмотра не нужен.
- tests — браузерные проверки; эти зависимости не нужны для работы сайта.
- PLAN.md, PROJECT.md, AGENTS.md — состояние и правила продолжения.

При добавлении изображения в галерею укажите href, data-viewer, data-pswp-width, data-pswp-height и data-caption; разместите ссылку внутри data-gallery. У превью должны быть width, height и alt. Оригинал не нужно загружать вместо маленького превью.

Фото главного экрана имеет варианты 480/800/1200 px. Его оригинал сохранён; подготовленные варианты кадрированы без ретуши. Сравнения показывают полные телефоны через индивидуальное CSS-кадрирование исходных композиций. Положение и масштаб задаются переменными --frame-x, --frame-y, --frame-zoom; соответствующие data-frame-position, data-frame-y, data-frame-zoom задают такой же кадр в PhotoSwipe. Цифры статистики набраны HTML-текстом в компактных карточках; по нажатию доступен исходник. Статистика и Reels имеют отдельные подписи периодов. Контактное фото получило отдельный нейросетевой вариант contact-restored.png; исходник сохранён.

## Движение

Все три сравнения используют sticky-сцену и нативную прокрутку. Прогресс обратим. При reduced-motion и низком окне показана обычная последовательность. Без JS доступны обе версии. Сторис идут целыми слайдами: предыдущий закрепляется под хедером, следующий наезжает снизу вместе с фоном и подписью проекта; при reduced-motion и низком окне остаётся обычный поток. Главное фото видно без прокрутки; после декодирования, если посетитель ещё вверху страницы, выполняется мягкое появление за 550 мс от opacity .65. Карточки результатов появляются сбоку на 18 px за 650 мс. Остальные появления на 56 px запускаются до полного входа блока в экран; уже видимый при загрузке контент не исчезает.

## Проверка

```sh
python -m pip install -r tests/requirements.txt
python -m playwright install chromium
```

В отдельном терминале запустите сервер. Затем задайте PORTFOLIO_URL и выполните tests/browser_checks.py. По умолчанию адрес проверки — http://127.0.0.1:8765/portfolio/. Для сервера из корня на 8000 используйте http://127.0.0.1:8000/.

PowerShell, пример с уже установленным Edge:

```powershell
$env:PORTFOLIO_URL = 'http://127.0.0.1:8000/'
$env:BROWSER_CHANNEL = 'msedge'
$env:TEST_OUTPUT = 'test-results'
python tests/browser_checks.py
python tests/gesture_checks.py
```

Gesture checks используют CDP Chromium, а не реальное устройство.

Проверки обновления от 13 октября доступны и на Node.js с Playwright 1.62.1 (использован установленный Edge). Playwright нужен только для тестов; можно использовать уже установленный пакет через NODE_PATH или установить его локально:

```powershell
npm install --no-save --package-lock=false playwright@1.62.1
$env:PORTFOLIO_URL = 'http://127.0.0.1:8000/'
$env:BROWSER_CHANNEL = 'msedge'
$env:TEST_OUTPUT = 'test-results'
node tests/refresh_checks.cjs
node tests/gallery_touch_checks.cjs
```

Первый сценарий проверяет первый экран, результаты, все подписи сторис, кадрирование, галерею, возврат фокуса и позиции на пяти размерах, а также reduced-motion и отсутствие JS. Второй проверяет pinch, pan, swipe и закрытие отдельно для сторис и сравнения. Результаты записываются в JSON, снимки — в TEST_OUTPUT.
